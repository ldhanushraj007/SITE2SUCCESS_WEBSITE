The Fellowship Selection Process

A fast, meritocratic 4-step benchmark evaluating practical building ability and commitment.

Step 01

Initial Intake

Submit your GitHub profile, past projects, and primary coding stack preferences.

Step 02

Practical Challenge

A 48-hour hands-on coding task focusing on API consumption, clean UI, and edge handling.

Step 03

Squad Interview

Technical conversation with studio leads on code architecture, AI tools, and collaboration.

Step 04

Active Sprint Placement

Onboarded into a live client squad, equipped with AI tooling, and assigned milestone deliverables.
